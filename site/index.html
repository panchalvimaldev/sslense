Free SSL certificates for IIS, installed and renewed automatically.

SSLense gets Let’s Encrypt certificates onto your IIS sites and keeps them renewed, and watches the certificates you buy elsewhere too, with a desktop app, a command line and a background service. No manual binding, no expired-certificate surprises.

Everything you need to secure IIS sites

Built for Windows administrators who want HTTPS working today and still working next year.

Guided issuance

Pick a site and its host names, run the pre-flight checks, and issue. SSLense validates the domain, installs the certificate and adds the HTTPS binding with SNI.

Safe binding swaps

After every change SSLense connects over HTTPS to confirm the new certificate is actually served. If not, it restores the previous binding automatically.

Automatic renewal

A Windows service checks hourly and renews when Let’s Encrypt recommends (ACME Renewal Information), with saved retries that survive reboots and respect rate limits.

Certificates from any provider

Bought a certificate from 123-reg, Sectigo or DigiCert? Create the request with a key that never leaves the server, install the issued certificate with the same safe swap, import a PFX, or adopt one already bound in IIS.

Expiry reminders, not daily checks

One digest a day, sent only when a certificate needs attention, from a set number of days before expiry until it is renewed. Snooze or turn off reminders per certificate, and get a notice before each automatic renewal.

Alerts that fit your setup

Email through any SMTP server or relay (including Microsoft 365 by IP address), Teams, Slack, Discord, Telegram, ntfy push, a heartbeat ping, and the Windows Event Log.

Health check and diagnostics

One command checks the service, permissions, IIS, DNS, port 80 and Let’s Encrypt, with a fix for each problem, and builds a redacted bundle for support.

Secure by default

Non-exportable private keys, no stored PFX files, secrets encrypted with DPAPI, a data folder limited to Administrators and SYSTEM, and staging until you choose production.

Three steps to HTTPS

Most single-site setups take a few minutes.

Install

Run the MSI. It installs the desktop app, the command line and the renewal service, and needs no separate .NET installation.

Issue the certificate

Choose your IIS site and watch live progress as SSLense validates the domain, installs the certificate and binds it.

Let it renew

The background service handles renewals and alerts you only when something needs your attention.

Prefer the command line?

Everything the desktop app does is also available from an elevated terminal, for scripts and remote sessions.

# Silent install, then check readiness and issue a test (staging) certificate
msiexec /i SSLense-x64.msi /qn
SSLense.Cli preflight --site "My Site" --hosts example.com,www.example.com
SSLense.Cli issue --site "My Site" --hosts example.com,www.example.com --email you@example.com --staging

# Day to day
SSLense.Cli status
SSLense.Cli health
SSLense.Cli notifications email --preset m365-relay --host contoso-com.mail.protection.outlook.com --from alerts@contoso.com --to ops@contoso.com
SSLense.Cli reminders set --start-days 45 --send-at 8

# A certificate from another provider: monitor the one in IIS, or request and install the next one
SSLense.Cli adopt --site "Shop"
SSLense.Cli csr --site "Shop" --hosts shop.example.com
SSLense.Cli complete --site "Shop" --certificate shop.crt --chain shop.ca-bundle

Questions

 

Is SSLense free?

Yes. SSLense is open source under the Apache License 2.0, so you can use it at no cost, including commercially, and read or change the code. Let’s Encrypt certificates are free as well.

What do I need to run it?

Windows Server with IIS, administrator access, and a domain that points to the server. Port 80 must be reachable from the internet for domain validation. The installer includes everything else, including the .NET runtime.

Where are my private keys stored?

Only on your own server, in the Windows certificate store, marked non-exportable. SSLense’s own data folder is restricted to Administrators and SYSTEM, and its secrets are encrypted with Windows DPAPI. Nothing is sent to SSLense.

Why does Windows show a SmartScreen warning?

Current releases are not code-signed yet, so Windows SmartScreen may warn the first time you run the installer. Signing is planned before version 1.0. Each release lists a SHA-256 checksum so you can verify the download.

Can SSLense manage a certificate I bought from another provider?

Yes. For a certificate from a provider such as 123-reg, Sectigo or DigiCert, SSLense creates the certificate request with a private key that never leaves your server, installs the issued certificate safely, imports a PFX, or starts monitoring a certificate already bound in IIS. It cannot renew those certificates itself, so it reminds you to order the renewal in time.

How do expiry reminders work?

The service sends one daily digest to your email, chat or Event Log, but only when a certificate needs attention: from a set number of days before expiry (30 by default), repeating until it is renewed. Let’s Encrypt certificates renew on their own; you hear about them only once beforehand or if renewal fails. Reminders can be snoozed or turned off per certificate.

How is SSLense different from other ACME clients?

SSLense is built only for IIS. It verifies each new binding over HTTPS and rolls back automatically if anything goes wrong, explains failures in plain language, includes a health check, and offers both a desktop app and a full command line.
